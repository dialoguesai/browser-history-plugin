# Dialogues Browser History 3.2.0

AI browser attribution setup is now distributed with the extension. Users can
configure Codex or Claude Code from a copyable request in **Connection settings →
Set up your AI tool**. The same setup page is linked from the toolbar popup.

- First installation opens connection settings; updates do not open extra tabs.
- The portable installer preserves existing instructions, supports dry runs and
  custom configuration directories, and installs the handoff helper from this repo.
- Verified handoffs identify the AI provider and real parent conversation, show
  the toolbar cursor, and release attribution when the work tool finishes.
- Ordinary history capture still only requires installation and Attach Dialogues.

## Download and install

Unzip `browser-history-plugin-v3.2.0.zip`. In your Chromium browser's extensions
page, enable Developer mode, choose **Load unpacked**, and select the unzipped
folder containing `manifest.json`. Open connection settings and Attach Dialogues.
Existing unpacked installations can replace their files with this version and
reload the extension, keeping the same folder/profile to preserve settings.

Optional AI-tool setup requires Node 20+, a supported tool running on the same
computer as the browser, and that tool's real current session identity. Follow
[AI tool setup](../ai-tool-setup.md) after attaching. Start a new chat after setup.

## Validation and scope

All 38 Node tests passed, including installer preservation/idempotence, first-run
behavior, attribution handoff, tab isolation, and release of control. The setup
page's tool selector and copy button were checked in a browser. The underlying
Codex handoff was verified live in Dia with a visit visible in the TOPOS timeline.
This does not claim a new live Claude Code or clean-browser installation test.

This GitHub release contains the unpacked extension and source. It does not
publish to the Chrome Web Store or include a signed/notarized Safari app.
Attribution is a cooperating-tool workflow, not automatic interception of all AI
actions. Conversation links also require the corresponding chat source in TOPOS;
downstream filtering requires compatible TOPOS node/UI versions.
