TOPOS · BROWSER HISTORY

Your browsing. Your agent’s work.
Clearly separate.

See who used the browser and return to the conversation behind an AI visit.

1. Connect your history

Attach Dialogues in connection settings, then browse as usual. No AI setup is needed to capture your own activity.

2. Set up your AI tool once

Choose a tool that runs on this computer and can control this browser. Copy the request below into that tool.

The tool installs instructions and a small local helper from this open-source repository. It preserves existing instructions and shows the files it will change. It does not change browser permissions or attach your account.

Prefer the terminal?

From the downloaded repository, with Node 20 or newer:

Omit --dry-run to install after reviewing the paths. Start a new chat afterward.




3. Check it works
In a new chat, ask your tool to open a page using TOPOS attribution. Before browsing, it should show Attributed to Codex or Attributed to Claude, and the extension icon should gain a cursor.
In your TOPOS timeline, check the visit’s AI name, provider, and parent conversation. Opening the conversation also requires that chat source to be synced. When the tool finishes, the cursor should clear.


What is automatic?
The extension can recognize some AI tab badges or groups without setup. Those signals can name the agent, but cannot identify its conversation. The handoff supplies that link.
The setup guides a cooperating work tool; it cannot force every browser action to identify itself. Claude Code requires a real session ID exposed to the helper. Claude’s regular chat mode, other tools, and remote agents are not covered by this installer. If identity is unavailable, the tool must report that instead of guessing.
